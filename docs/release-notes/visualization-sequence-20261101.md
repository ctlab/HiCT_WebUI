# Visualization, exports and nucleotide inspection

- Lower and upper threshold sliders have separate hit areas. Automatic ranges aggregate finite raw and processed extrema from loaded viewport tiles; opening or panning a map no longer starts a full-resolution scan. These are **loaded-tile ranges**, not exact viewport-pixel or whole-map extrema. The explicit whole-map scan remains available. User thresholds are retained while tiles load.
- Opening another map retains compatible visualization settings and caption styling. An explicit Open Wizard preset still takes precedence. A custom graph bound to an old secondary map or external track cannot be copied safely and produces a warning; new-map weight diagnostics are evaluated again.
- Map exports omit the minimap. Whole-map export reserves space for external labels and restores the live viewport afterward. Caption placement controls support above, below, left, right and inside per label track. SVG/PDF text remains editable; contact pixels remain raster data.
- Electron and Tauri remember the directory of the last successful export. Cancellation or a failed write leaves the preference unchanged. Ordinary browser downloads use the browser's destination policy.
- With FASTA linked, zooming beyond a screen-sized finest contact bin opens a read-only nucleotide view. Its row and column windows use padded sequence coordinates, including configured inter-scaffold separators and explicit imported AGP gaps. Hovering a real base shows current gap-free assembly and original FASTA coordinates, direction, contig and scaffold. Inserted Ns explicitly have no original base or contact bin. Return to the contact map or press Escape to resume editing at the same map location.
- Sequence zoom now stays inside the workspace. Each axis window displays its visible annotation lanes, the colored FASTA track and the sequence ruler in that order, sharing horizontal scrolling. Existing feature colors, strands, exon/coding blocks, signal styles and per-axis visibility are reused. Features are split at inserted gaps; synthetic Ns never inherit annotation signal. An intervening edit in another client rejects the annotation response with a refresh warning.
- The padded sequence axes remain distinct from the gapless contact matrix: inserted Ns do not have Hi-C measurements. Map-image exports and assembly edits currently require returning to the contact map. The underlying gap-free FASTA axis track remains aligned with contact coordinates.

Requires the matching JVM revision with `/sequence/region` padded projection and tile-statistics responses. Requests are bounded to 4,096 bases, carry the displayed assembly revision, and use indexed FASTA access. Structural edits, undo/redo, names and gap settings invalidate the sequence projection. Native processing and the file format are unchanged.

Validation evidence and manuscript claims belong to the accompanying review bundle. Passing CI on newer macOS runners plus a deployment-target audit does not establish execution on physical macOS 12.3 devices.
